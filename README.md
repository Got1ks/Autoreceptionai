# AutoReception AI — голосовой тест

Статическая страница для голосового тестирования агента AutoReception RU из браузера телефона.

- На странице нет секретов: ключ Retell хранится только в n8n.
- Звонок создаёт серверная часть в n8n после проверки PIN и лимитов: не больше 10 звонков в сутки, до 5 минут каждый, блокировка IP после 5 неверных PIN.
- Разрешение на CORS — только ограничение браузерных запросов, не авторизация.
