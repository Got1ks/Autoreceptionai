# AutoReception AI — голосовой тест

Статическая страница для голосового тестирования агента AutoReception RU из браузера телефона.

- На странице нет секретов: ключ Retell хранится только в n8n.
- Звонок создаёт серверная часть в n8n после проверки PIN и лимитов: не больше 10 звонков в сутки, до 5 минут каждый, блокировка IP после 5 неверных PIN.
- Разрешение на CORS — только ограничение браузерных запросов, не авторизация.

## Панель владельца (`/panel/`), только чтение

- Вход через Google Identity Services. Подпись ID token, `iss`, `aud`, срок и `sub` из белого списка проверяет сервер (n8n) при каждом запросе; без разрешённого `sub` данные не выдаются.
- На странице нет секретов и данных: расписание и заявки приходят с сервера после входа. Client ID Google — не секрет.
- Токен хранится только в памяти вкладки; страница ничего не пишет в консоль, localStorage и cookie.
- Операций записи нет. Разделы «Клиенты» и «ИИ-чат» — демонстрационные и так помечены.
